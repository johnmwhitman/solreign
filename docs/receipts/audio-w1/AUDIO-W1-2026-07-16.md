**`hith_kick.ogg` (attribution) → real file is `Resources/Audio/Effects/hit_kick.ogg` (no "h" after "hit"). SPARED — actively used.**

- `git ls-files Resources/Audio/Effects | grep -i "kick\|hith"` → only `hit_kick.ogg` exists on disk; no file named `hith_kick.ogg` has ever existed in this repo's git history (`git log --all --full-history -- '*hith_kick*'` → empty).
- The attribution entry (`Resources/Audio/Effects/attributions.yml:195`, `files: [hith_kick.ogg]`, `license: Custom`, copyright Taira Komori) is a one-letter typo of the real filename `hit_kick.ogg`.
- `hit_kick.ogg` is referenced in three places:
  - `Resources/Prototypes/SoundCollections/bible.yml:9`
  - `Resources/Prototypes/Entities/Mobs/base.yml:145` — the **base mob melee-hit sound**, i.e. this fires on essentially every unarmed hit against every mob in the game.
  - `Content.Server/_Solreign/TrainingCombat/SolreignTrainingBatonComponent.cs:68` — `new SoundPathSpecifier("/Audio/Effects/hit_kick.ogg")`, a C# ResPath literal.
- **Verdict: this is one of the highest-exposure sounds in the flagged set, not an orphan.** Deleting it would have broken base mob combat audio. Left the file and its (mis-typed but still-valid) attribution entry untouched.

**`rain2.wav` (attribution) → real file is `Resources/Audio/Effects/Weather/rain2.ogg`. SPARED — actively used.**
