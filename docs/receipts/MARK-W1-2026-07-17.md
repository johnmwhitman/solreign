## [needs verification] tag resolutions (W1-touched)

- **T1 — §3.1 slot claim atomicity** ("fold the count into the INSERT … or a two-statement
  transaction"): **RESOLVED — both halves.** The INSERT carries
  `slot_index = (SELECT COUNT(*) FROM mark)` in its VALUES *and* runs inside
  `BeginTransaction(deferred: false)` (BEGIN IMMEDIATE — the `AddRoundRecordAsync` idiom), so the
  write reservation is taken *before* the count subquery evaluates. Cross-instance proof:
  `RacingClaims_DistinctAccounts_AcrossStoreInstances_GetDistinctDenseSlots` races two independent
  store instances on one file — both claim, slots come back `{0,1}`, never torn. Same-account race
  hands exactly one win (`ON CONFLICT(user_id) DO NOTHING` + rowcount, the FirstDeath copy).
- **T2 — §7 store-test fixture** ("reuse the same in-memory SQLite fixture the first-death store
  tests landed with"): **RESOLVED, with a correction.** `FirstDeathStoreTests` does NOT use
  in-memory SQLite — it uses per-test unique temp FILE DBs (`Path.GetTempPath()` + GUID, `-wal`/
  `-shm` teardown), which is what makes the two-instance racing tests possible at all.
  `MarkStoreTests` copies that harness verbatim.

  itself is W2): **AUDITED.** `BaseStructure`
