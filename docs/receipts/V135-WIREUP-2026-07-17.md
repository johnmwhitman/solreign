## #5 — Gateway machine on Oasis

**Census claim re-verified, with a correction the census didn't have:** the only placed `proto: Gateway`
anywhere in the repo is on Terminus (`solreign_terminus.yml:138708`, minPlayers 70, never
population-eligible) — confirmed. But reading that block found **both** Terminus instances carry
`missingComponents: [ActivatableUI, UserInterface, Gateway]` — i.e. the Terminus placement is a
decorative `BaseGateway` frame with its actual functional components stripped, not a working gateway.
Copying it verbatim to Oasis would have produced a second non-functional machine.

Further: `GatewayComponent.Enabled` defaults to **false** in C#
(`Content.Server/Gateway/Components/GatewayComponent.cs`) and nothing flips it for a map-authored station
gateway — only `GatewayGeneratorSystem.GenerateDestination` calls `SetEnabled(true)`, and only on the
destinations it spawns on the generated planet maps (confirmed those planets already come up correctly
enabled every round — the census's "generation already runs every round" claim holds). So a bare
`proto: Gateway` placement with no override would have loaded fine and passed every structural test while
being just as inert as the Terminus reference.

**Wired:** full `Gateway` prototype (retaining `ActivatableUI`/`UserInterface`/`Gateway`, unlike Terminus)
placed at Oasis Cargo Bay, uid 900951, pos 19.5,14.5, parent 31 — plus an explicit `enabled: true`
component override, which is the one missing piece to make it actually functional. No CVar or config
change needed or discovered; this is entirely a map-content fix.

## #6 — RespawnDeadRule into the low-pop path

**Rule behavior re-verified before wiring (for an honest go-live card description):** `RespawnDeadRule`
(`Resources/Prototypes/GameRules/roundstart.yml`) = `RespawnDeadRuleComponent.AlwaysRespawnDead: true` +
`RespawnTrackerComponent` (`respawnDelay: 10s`, `deleteBody: false`). `RespawnRuleSystem` auto-queues
anyone who dies while the rule is active and respawns them via `GameTicker.MakeJoinGame` 10 seconds
later; the original body is left in place (not deleted), the player just gets a fresh one. Genuinely
anti-spectate, not a death-penalty removal in disguise.

**Wired:** added to `SolreignAntagsOnSpawn`'s `rules:` list
(`Resources/Prototypes/_Solreign/GameRules/antags_on_spawn.yml`). This preset is reachable today via the
player preset-vote (`showInVote: true`, independent of whether SolreignSecret itself is deployed — that's
census #1, explicitly skipped this wave).
