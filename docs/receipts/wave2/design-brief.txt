TASK: Design pixel-art IDLE ANIMATIONS for 4 Space Station 14 sprites (32x32 RSI states). They will be implemented as programmatic per-pixel edits (Python/PIL) on the existing static art — you design, you do NOT draw.

THE SPRITES (with in-game flavor):
1. unicorn.rsi state "icon" — a unicorn delighter entity. Likely feature: horn sparkle/shimmer, or mane glint.
2. exec_recharge_pod.rsi — "executive recharge pod": a walnut-veneer vampire coffin, Solreign Wellness Division. In-game it renders layers: "base" always + "closed" (door) when shut + "paper" sticker. Propose which state(s) to animate (e.g. a status LED breathing on the door). "open" state also provided.
3. pool_noodle.rsi state "icon" — "recreational compliance baton", a foam pool noodle.
4. scarlet.rsi state "scarlet" — Scarlet, a pet dog mob, 4 DIRECTIONS (tiles in order S,N,E,W). Animation must be designed PER DIRECTION (e.g. tail wag, ear flick). Same frame count/delays for all 4 directions.

HARD CONSTRAINTS:
- Frame 0 = the original sprite, byte-identical. 2-4 frames total, looping.
- Only maskable edits, expressed EXACTLY as: (a) palette letters from the maps below, optionally bounded by a rectangular region [x0,y0,x1,y1] inclusive; (b) explicit pixel coordinate lists. Allowed ops per frame: brightness multiply (factor), alpha set (0-255), single-pixel toggle on/off, single-pixel copy from->to, color lerp toward a target rgb (t 0-1).
- Silhouette must stay stable — subtle ambient idle, NOT a redraw. Untouched pixels must remain byte-identical.
- Delays per frame in seconds: ambient props 0.3-0.6s, sparks/twinkles 0.1-0.25s. Total loop <= ~2.5s.
- If a sprite is a poor candidate, say "skip" with reason.

OUTPUT: STRICT JSON only, schema:
{"sprites":[{"rsi":"unicorn","state":"icon","verdict":"animate|skip","concept":"one-line",
 "frames":3,"delays":[0.4,0.4,0.4],
 "masks":{"maskname":{"letters":["a","b"],"region":[x0,y0,x1,y1]} or {"pixels":[[x,y],...]}},
 "frame_ops":[{"frame":1,"ops":[{"mask":"maskname","op":"brightness","factor":1.25},
   {"op":"px_off","at":[x,y]},{"op":"px_copy","from":[x,y],"to":[x,y]},
   {"mask":"maskname","op":"alpha","value":150},{"mask":"maskname","op":"lerp","to":[255,255,255],"t":0.3}]}],
 "per_direction":{"S":{...same masks/frame_ops keyed if needed...}} // only for scarlet; masks/coords are per-TILE local coords
}]}

Note tile-local coordinates: for scarlet, give masks per direction tile (S,N,E,W), coordinates local to that 32x32 tile.

PIXEL MAPS AND PALETTES FOLLOW. "." = transparent. Letters = palette entries (rgb + count listed above each map). Row numbers on the left; columns are x=0..31 left to right.
