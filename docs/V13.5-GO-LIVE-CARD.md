## 🔴 NEW MANDATORY GATE — LIVE SMOKE ROUND before/at cut (the v13.4 lesson)
**Battery-green ≠ works in a live round.** v13.4 shipped with every suite green and still demoted
every player to Passenger on the live box. Two new, non-negotiable steps:

1. **Automated per-map cut-gate (rides the battery).**
   `SolreignRoundStartJobSpreadGateTest` starts a REAL multiplayer round on EACH of the 7 Solreign
   maps and asserts (a) round enters InRound, (b) diverse job preferences spread across real jobs
   (engineers > 0 — the incident canary — plus a non-Passenger majority and several distinct jobs),
   (c) no round-start throw / no aborted spawn. This is the permanent lock that would have caught the
   all-passenger fingerprint. It MUST be green (all 7 maps) at cut.
   - Run filtered: `dotnet test Content.IntegrationTests/Content.IntegrationTests.csproj -c Debug \
     --filter "FullyQualifiedName~SolreignRoundStartJobSpreadGateTest"`
   - LIMIT (documented, not a gap): in-test prefs load synchronously, so the gate proves healthy
     job spread + no throw — it does NOT reproduce the live un-loaded preference RACE. That race is
     covered by the live smoke round (step 2) + the diagnostic warning.

2. **Manual LIVE SMOKE ROUND on the box, before/at cut.** After apply, actually START a round on the
   live server and confirm crew get real jobs (not everyone Passenger). This is the step v13.4
   lacked. If the `_sawmill.Warning` prefs-miss line fires, DO NOT proceed — it is the exact
   all-passenger fingerprint (a preference-LOAD condition).

3. **Verify `game.lobbyenabled` is set INTENTIONALLY.** The all-passenger live trigger correlates
   with the lobby-disabled path (it skips the readiness gate the DEBUG assert guards). Before cut,
   confirm `game.lobbyenabled` in `server_config.toml` is whatever the operator INTENDS (not a
   silent default) and record the intended value in the cut header.

## Lesson banner (why this card grew a live-smoke gate)
v13.4 was fully battery-green and still all-Passenger on the live box: the failure was a RELEASE-only
preference-LOAD race whose only guard (`IsLoadComplete`) was a `#if DEBUG` assert, invisible in prod.
The fix is layered: (1) a diagnostic warning on the live path so the next occurrence is legible;
(2) an automated per-map cut-gate that proves a real round starts with healthy job spread on all 7
maps; (3) a MANDATORY manual live smoke round at every cut. Green tests describe the harness; the
live round describes the server. Cut on both.
